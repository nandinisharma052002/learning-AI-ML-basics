# AI/ML Learning Repository

This repository contains my hands-on experiments and learning projects in Artificial Intelligence, Machine Learning, and related technologies. The goal is to build practical understanding by implementing concepts from scratch and exploring popular frameworks and tools.

## Repository Structure

### FastAPI

A collection of basic FastAPI examples used to understand:

* API development fundamentals
* Request and response handling
* POST endpoint creation
* Testing APIs locally
* Backend integration concepts

### RAG with LangChain

A minimal Retrieval-Augmented Generation (RAG) implementation built for learning purposes using:

* LangChain
* ChromaDB
* Groq LLM
* PDF document ingestion
* Embeddings and vector search
* Question answering over custom documents

This project explores the complete RAG pipeline:

1. Load a document
2. Split into chunks
3. Generate embeddings
4. Store vectors in ChromaDB
5. Retrieve relevant context
6. Generate answers using an LLM

## Objectives

* Learn AI/ML concepts through implementation
* Explore modern LLM frameworks and tooling
* Understand vector databases and retrieval systems
* Gain experience with API development and deployment patterns
* Build a foundation for more advanced AI applications
